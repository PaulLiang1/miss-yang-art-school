# Miss Yang's Art School — seven website directions

Open `index.html`. Each folder is a complete two-page static site (home + Little Artists gallery),
all fonts and images local, no build step.

- 01-atelier — the monograph
- 02-prospectus — the prospectus
- 03-scrapbook — the studio table
- 04-gallery-night — after hours
- 05-ink — ink and paper (墨与纸)
- 06-line — one line (GSAP motion)
- 07-gallery — a quiet room

Content and fixed decisions follow the project handover. Nothing here needs a server for the pages
themselves; folder links (such as `little-artists/`) work over http, not `file://`.
